# Tri-Modal-ECG paper

This folder contains the LaTeX manuscript for **Tri-Modal-ECG**.

## Files

| File | Purpose |
|---|---|
| `main.tex` | Full manuscript (Cell Press / Scientific Data style, adapted from MEETI). |
| `references.bib` | BibTeX references. Inherits the MEETI bib and adds NeuroKit2, Pan-Tompkins, WFDB, OpenCV, NumPy, Matplotlib, Parquet, CLIP/BLIP-2/XrayGPT/PathChat, ECG-Chat, MEETI itself, etc. |
| `numbered.bst` | Numbered (AMA-style) bibliography style, copied from the MEETI release. |
| `figures/` | All 33 figures referenced from `main.tex`. Generated by `scripts/viz_paper.py`, `scripts/viz_overview.py`, `scripts/viz_examples.py`, `scripts/viz_tasks_bc.py`, `scripts/viz_extras.py`, `scripts/viz_12lead_only.py`. |
| `dataset_stats.json` | Filtered descriptive statistics for the structured measurements (sentinels removed). |
| `check_paper.py` | Static sanity check: every `\includegraphics{...}` resolves to a file, every `\cite{...}` is in the bib, every `\ref{...}` has a matching `\label{...}`. |

## Building the PDF

The manuscript compiles with the standard `pdflatex` + `bibtex` cycle. From this folder:

```bash
pdflatex main
bibtex   main
pdflatex main
pdflatex main
```

Or with `latexmk`:

```bash
latexmk -pdf main.tex
```

If you do not have a local TeX distribution installed, the easiest path is Overleaf:

1. Create a new project, upload everything in this folder (including `figures/`).
2. Make sure the document compiler is set to `pdfLaTeX`.
3. Compile.

The same files build cleanly under TeX Live 2023+, MiKTeX 22+, MacTeX 2023+, and Overleaf's default toolchain.

## Sanity check

Before compiling, you can run the static checker to confirm that no figure / citation / cross-reference is broken:

```bash
python check_paper.py
```

Expected output:

```text
=== Figure check ===
  unique figures referenced : 31
  missing figures           : none
=== Citation check ===
  cite keys used            : 30
  bib keys present          : 45
  missing cite keys         : none
  unused bib keys           : 15 (informational)
=== Cross-reference check ===
  labels present            : 42
  refs used                 : 39
  missing refs              : none

All checks passed.
```

## Regenerating the figures

If you want to rebuild the figures from the on-disk dataset:

```powershell
cd D:\Coding\MU\Tri-Modal_ECG
.\ecg_env\Scripts\Activate.ps1
python scripts/find_examples.py     # picks hero studies into report_assets/examples.json
python scripts/viz_overview.py
python scripts/viz_examples.py
python scripts/viz_tasks_bc.py
python scripts/viz_extras.py
python scripts/viz_12lead_only.py
python scripts/viz_paper.py         # paper-only figures + copies into paper/figures/
```

`viz_paper.py` is the script that produces the four paper-original figures
(`fig_feature_matrix`, `fig_modality_montage`, `fig_pipeline_paper`,
`fig_taskB_before_after`, `fig_taskB_examples`) and copies the polished
report figures into `paper/figures/` so the manuscript is self-contained.
